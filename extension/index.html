Les captures sont fournies par mshots et mises en cache localement pendant 30 jours. Le site source est transmis au service de miniatures.

Le scan couvre tous les favoris web actifs (hors adresses locales) et vérifie une seule fois chaque URL identique. Seuls HTTP 404/410 sont considérés comme morts ; les erreurs réseau ou blocages restent temporaires. Les liens morts en quarantaine ont leur contrôle quotidien séparé.

Les favoris envoyés à l’historique sont déplacés dans un dossier Chrome dédié, hors de vos favoris actifs. Restaurez-les à tout moment à leur emplacement d’origine.

Deux sauvegardes distinctes : les exports (fichiers JSON/HTML téléchargés, boutons dans l'en-tête) et les instantanés locaux pris avant chaque nettoyage — restaurables depuis la colonne Historique. La poubelle se gère dans son onglet.

Sauvegarde complète

Export des favoris actifs en fichier téléchargé par Chrome. L’historique local conserve un instantané avant les exports, nettoyages, restaurations et purges.

Les exports JSON et HTML sont disponibles dans l’en-tête de l’application.

Quarantaine

Les éléments sont séparés selon leur origine. Les liens confirmés en 404/410 restent 30 jours en quarantaine ; les doublons restent restaurables jusqu’à une purge manuelle.

Les liens morts en quarantaine sont vérifiés automatiquement au plus une fois par jour.

Sessions & onglets

Toutes les 5 minutes, 20 versions distinctes maximum. Aucune fermeture d'onglet : un favori devient une session permanente.

Chaque jour à l'heure choisie, tous les onglets ouverts deviennent une session datée « Session du jour » — une par jour, visible dans la timeline.

L'heure de bascule : la journée en cours est enregistrée, la suivante démarre neuve.

Dépose la session quotidienne en JSON dans le dossier de téléchargements de Chrome, sous-dossier « PK Web Memory ». Les sessions ne vivent sinon que dans le stockage local de l'extension : pointez le dossier de téléchargements vers votre Google Drive (ou créez un lien symbolique) pour une sauvegarde cloud automatique. Fichier ré-importable dans l'onglet Sauvegardes.

Ferme les onglets enregistrés (épinglés conservés) et laisse une fenêtre neuve : chaque matin démarre sur une session vide.
